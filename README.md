## 🚀 How to Run Locally on Your Computer

You don't need to install anything special to see this website on your computer:

### Option 1: Just Double Click (Easiest!)
1. Download or clone this repository.
2. Find the `index.html` file in your folder.
3. Double-click it to open it directly in any web browser (Chrome, Safari, Edge, Firefox).

### Option 2: Using Python (Local Server)
If you have Python installed, open your terminal inside this folder and run:
```bash
python3 -m http.server 8000
```
Then open your browser and go to: `http://localhost:8000`

## ✏️ How to Update the Content

If you want to update information in the future:

1. **Change Text / Projects:** Open `index.html` in VS Code or any text editor and edit the text.
2. **Change Photo:** Replace `assets/profile.jpg` with a new image keeping the same filename.
3. **Update Resume:** Replace `assets/Khushboo_Pandey_UMASS.pdf` with your new resume PDF.
4. **Push to GitHub:**
   ```bash
   git add .
   git commit -m "Update portfolio content"
   git push origin main
   ```
   GitHub Pages will automatically update your live site within 1–2 minutes!
